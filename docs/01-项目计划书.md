## 1. 项目概况

本项目是经典《坦克大战》的联机复刻，保留砖墙、钢墙、水域、冰面、草丛、基地等经典地形，加入地图编辑、AI 地图生成、道具升级、房间观战、大厅战队等联机功能。项目由 5 人共同完成，覆盖桌面端、Web 后端、移动端 H5 三类应用端。

| 项目要素 | 内容 |
|---|---|
| 项目名称 | 坦克大战·联机复刻 |
| 项目仓库 | cs24104-TankBattle |
| 方向 / 难度 | 网游方向 / ★★★★ |
| 应用端 | 桌面端 + Web 后端 + 移动端 H5 |
| 桌面端技术栈 | Kotlin 2.4.21 + JDK 21 + Gradle 9.8.1 + LibGDX + Tiled 1.12.2 |
| 工具语言 | Python 3.12（离线地图生成/校验） |
| 服务端技术栈 | Spring Boot + WebSocket + Netty |
| 移动端技术栈 | Vue3 + WebSocket + ECharts |
| 开发模式 | 2 周一个 Sprint，Git feature → develop → main |

## 6. 质量、成本与配置

质量目标：单测覆盖率 ≥60%（地图模块 ≥70%）；地图校验通过率 100%；1280×720 下 60 FPS；地图加载 <200ms；AI 生成单张 <2s；10 局联机无崩溃；ktlint/detekt 0 error。

成本：200 人时 × 30 元/人时 = 6,000 元；AI API 约 100 元；工具全部使用教育/开源授权；合计 6,100 元。控制：每周登记工时；每人 AI 配额 20 元；不采购付费素材。

配置与变更：`main` ← `develop` ← `feature/<姓名拼音>-<模块>`；main/develop 保护，PR + 1 人评审；Conventional Commits。基线：M2 需求、M3 设计、M4 代码。变更走 Issue → 影响分析 → 组长 + 1 名组员审批 → 实施 → 回归。
