# 操作步骤（GitHub / EA / 打包 / 提交）

> 这些是需要鼠标或网页操作的部分；命令行/生成代码已经由 AI 做好。按顺序做即可。

## 1. 上传 GitHub（10 分钟）

### 1.1 新建仓库

1. 打开 <https://github.com/new>。
2. Repository name 填 `cs24104-TankBattle`。
3. 选 Public 或 Private（老师能看即可）；**不要**勾选 Add README / .gitignore / License。
4. 点 Create repository。

### 1.2 在本地仓库执行 3 条命令

打开 PowerShell，进入 `D:\NEWJOB\SHIYAN1\cs24104-TankBattle`，把 `<你的GitHub用户名>` 换成你的用户名：

```powershell
git remote add origin https://github.com/<你的GitHub用户名>/cs24104-TankBattle.git
git push -u origin main
git push origin develop
git push origin feature/yaoshuai-map
```

如果提示 `remote origin already exists`，先执行 `git remote set-url origin https://github.com/<你的GitHub用户名>/cs24104-TankBattle.git` 再 push。

成功后，GitHub 仓库首页能看到 `main`，分支下拉里能看到 `develop` 和 `feature/yaoshuai-map`。

> 截图位置：GitHub 仓库首页 + 分支列表；如果老师要仓库链接，把 URL 发给他。

## 2. 打开 EA 学 3 个操作（15 分钟）

### 2.1 打开工程

双击 `model/TankBattle.qea`，或用 EA 17.2：`File → Open Project` 选这个文件。

左侧 Project Browser 里展开：

```
01 项目计划 → 项目 WBS（编码阶段与 B 模块展开）
02 需求     → 地图系统用例图
03 设计     → 系统构件图 / 地图系统类图 / 地图编辑与 AI 生成活动图
```

双击图名即可打开；`Ctrl + 鼠标滚轮` 可以缩放。

### 2.2 操作 1：改一个名称

双击图里任意一个元素（如 `4.4 地图编辑器与 AI 生成`），在 Properties 里把 Name 改成你想试的名字，点 OK；再改回来或保留都可以。

### 2.3 操作 2：改一个颜色

右键元素 → `Appearance → Default Appearance`（或工具栏颜色按钮），选一个浅色，OK。图里能看到颜色变化即可。

### 2.4 操作 3：导出 PNG

右键图空白处 → `Save as Image`（或 `Publish → Save as Image`），格式选 PNG，保存到 `report/assets/ea/`，文件名建议：

```
fig3-1-component.png
fig3-2-usecase.png
fig3-3-class.png
fig3-4-activity.png
fig2-1-wbs.png
```

> 报告里的图已经放在 `report/assets/ea/`，你只是学操作；如果改了图，重新导出同名文件，我再替换 PDF。

### 2.5 答辩时能说的 3 句话

- “这个 `.qea` 是 EA 17.2 工程，5 张图都在里面，图是从 EA 导出的。”
- “WBS 用 Task 元素做层级，4.4 展开到 L4；构件图/用例图/类图/活动图分别对应 03 设计包和 02 需求包。”
- “地图类图里 MapService 是接口，CollisionService 实现它；生成器/校验器分开，AI 只给参数。”

## 3. 审 PDF（20 分钟）

打开 `report/cs24104-2024210622-姚帅-坦克大战联机复刻-实验一软件项目计划.pdf`，按这 5 条看：

1. 封面：姓名/学号/角色/项目名对不对；版本“第一阶段（初稿）”。
2. 目录：页码和正文是否一致（Word 已自动更新；不应有“目录将在 Word 中更新”）。
3. 图：图 2-1 WBS、图 3-1 构件、图 3-2 用例、图 3-3 类图、图 3-4 活动图是否清楚；看不清告诉我放大/拆图。
4. 表：表 2-2 WBS 工时合计 200、你的 48、团队 5 人/15 项功能/3 类端是否对。
5. 文字：有没有不像你写的句子；第 15~16 页提交说明是否为“审完再打包”。

要改就说“第 X 页第 X 段改成……”，我改完重新导 PDF；目录页码会自动重排。

## 4. 审完再打包（10 分钟）

**先不要打包**；你确认 PDF 后，运行：

```powershell
python src\make_zip.py
```

它会在仓库根目录生成：

```
cs24104-2024210622-姚帅-坦克大战联机复刻-实验一软件项目计划-源码.zip
```

包含：README、docs、report（docx/pdf/图）、model（.qea）、src（生成脚本）、maps（schema/示例）；**不含**第三方库、`__pycache__`、日志、水印原图。

如果不想跑脚本，手动压缩这些内容也可以：

```
README.md  .gitignore  docs/  report/  model/TankBattle.qea  src/  maps/
```

## 5. 提交（5 分钟）

- PDF 单独提交，文件名：`cs24104-2024210622-姚帅-坦克大战联机复刻-实验一软件项目计划.pdf`
- 源码 zip：同名 + `-源码.zip`
- 提交后截图留证；如果平台只收一个压缩包，把 PDF 也放进 zip 根目录再传。

## 6. 如果出问题

| 现象 | 处理 |
|---|---|
| `git push` 要求登录 | 用 GitHub 网页登录/Personal Access Token；或先 `git remote -v` 看地址 |
| EA 打开提示试用版 | 仍可打开/导出；报告图已做黑白化处理，不影响评阅 |
| PDF 目录页码不对 | 告诉我，我重新用 Word 更新域并导出 |
| 图太小看不清 | 告诉我图号，我放大或拆成两张，报告会多 1 页 |
| 平台不接受 zip 名 | 按平台要求改名，内容不变 |
